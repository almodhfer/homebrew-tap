# Homebrew tap for Alef

[Alef](https://github.com/almodhfer/alef-term) is an Arabic-first terminal
emulator. Install it on an Apple Silicon Mac with:

```sh
brew install --cask almodhfer/tap/alef-term
```

The app is not signed with an Apple developer certificate; the cask clears the
macOS download flag after installing so that it opens normally.
